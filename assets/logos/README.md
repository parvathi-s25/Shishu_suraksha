# Logo Assets for Splash Screen

Place the following logo files in this directory:

## Required Files:

1. **ap_government_logo.png** - Government of Andhra Pradesh official logo
2. **wcd_department_logo.png** - Department of Women Development & Child Welfare logo
3. **rtih_logo.png** - RTIH (Rajiv Gandhi Institute of IT & Health) logo
4. **final_app_logo.png** - Final ShishuSuraksha AI app logo with family illustration

## Specifications:

- Format: PNG with transparency
- Size: 512x512px (will be scaled in app)
- DPI: 72 or higher
- Color mode: RGB/A
- Background: Transparent

## Notes:

If logo images are not available, the splash screen code includes fallback renderers using CustomPaint that will display colored circles and illustrations instead.
