Shishu Suraksha - Admin Dashboard (Prototype)

This is a minimal Next.js prototype scaffold for the Admin Web Dashboard (Section C).

Quick start:

1. Install dependencies

```bash
cd web_admin
npm install
```

2. Run in development

```bash
npm run dev
```

3. Build and start

```bash
npm run build
npm start
```

Notes:
- This is a frontend scaffold only. It expects APIs or exported CSV/JSON from the Flutter app or backend.
- Future work: add district heatmap, sortable high-risk table, worker performance analytics, and alerts.
